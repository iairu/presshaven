# Glossary

This page contains definitions of key terms and concepts used in this documentation.

## Core Concepts

- **Honeypot**: Decoy system designed to attract and engage attackers.
- **IDS**: Intrusion Detection System, e.g., Suricata network IDS.
- **SIEM**: Security Information and Event Management platform.

## Detection Terms

- **CVE**: Common Vulnerabilities and Exposures identifier.
- **SID**: Suricata rule identifier.
- **WSTG**: OWASP Web Security Testing Guide category.

## Architecture Terms

- **Lua Module**: Scripted detection logic executed within the honeypot backend.
- **Pattern**: Matched attack signature or exploit pattern.

## Operations Terms

- **Hardening**: Security posture improvements for production deployment.
- **Runbook**: Operational troubleshooting and response procedures.
